# Windows で sudo コマンドが使えるようになった

ちょっと前から Windows で sudo コマンドが使えるようになったので便利になりました。

私はよくシンボリックリンクを作成するときに mklink を使うのですが管理者モードでないと実行できないので新しいウィンドウを開く必要がありました。 sudo コマンドを使うと設定次第で新しいウィンドウを開かずインラインで実行できます。

初めて Windows の sudo を実行したときは Linux の感覚で `sudo mklink` とやったらエラーになりました。なんと `sudo cmd.exe` で管理者モードの cmd.exe を起動する必要があるのですね。でもこれ挙動が sudo ではなく su ですね。

シンボリックリンク作成は cmd.exe でなくても PowerShell でもできるのですが、 `New-Item -ItemType SymbolicLink -Target <original file> -Path <new file>` という長ったらしいコマンドが必要なので cmd.exe を愛用しています。
