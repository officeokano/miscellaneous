# YAML front matter の書き方を変えた

タイトルの通り YAML front matter の書き方を変えました。今までは

```
---
title: YAML front matter の書き方を変えた
date: 2026-02-15
author: officeokano
---
```

のようにできるだけ無駄な空行は避けるようにしていたのですが、今後は

```
---

title: YAML front matter の書き方を変えた
date: 2026-02-15
author: officeokano

---
```

のように `---` とキーの間に空行を挟むことにしました。これは front matter に対応していない markdown 閲覧ソフトで見た場合に `---` の直前の行がタイトル行として表示されることを防ぐためです。最後の行に `title:` を置けばいいのですがさらにその直後に本来のタイトル行が来ると見た目がスマートではなくなるしタイトルは最初の行に書きたいのでこのようになりました。
